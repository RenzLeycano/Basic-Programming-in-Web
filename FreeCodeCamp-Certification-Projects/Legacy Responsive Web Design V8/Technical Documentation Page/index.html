Selective Structures

A selective structure is a decision-making program that bases its value on the conditions the programmer set. It allows varied execution paths based whether certain conditions are met.

The following are key relational and boolean operators that can be useful when creating a condition for selective structures:

  • == : equal to
  • != : not equal to
  • > : greater than
  • < : less than
  • >= : greater than or equal to
  • <= : less than or equal to
  • && : AND (if both operands are true, it returns true, otherwise false)
  • || : OR (if one of the operands are true, it returns true, otherwise false)
  • ! : NOT (reverses logical state)

  • If...Else

    If...Else allows the execution of different code blocks based on the set conditions. While an If statement is mandatory, an Else statement can be optional, although no execution is done if the condition in the if statement is false.

    If the condition is met or the logical state is true, the code block inside the if statement is executed, otherwise, the else statement.

    • int number = 10;

    if (num % 2 == 0) {
    System.out.println("The number is even.");
    } else {
    System.out.println("The number is odd.");
    }

  • Else if

    When it comes to selective structures that want execution paths greater than 2, an else if statement can be used.

    If an if statement or else if statement already has a logical state of true, the rest of the statements will NOT be executed.

    • int number = 10;

    if (num == 0) {
    System.out.println("The number is zero.");
    } else if (num % 2 == 0) {
    System.out.println("The number is even.");
    } else {
    System.out.println("The number is odd.");
    }

    Switch

    A switch statement executes a code block with a case label whose value matches the expression. If the expression doesn't have a match, it falls into default.

    This is useful when evaluating exact matches for integers, strings, or characters.

    String number = "10";

    switch (number) {
    case "1":
    System.out.println("One");
    break;
    case "5":
    System.out.println("Five");
    break;
    case "10":
    System.out.println("Ten");
    break;
    default:
    System.out.println("A number.");
    break;
    }

Iterative Structures

An iterative structure allows repeated execution of a specific code block if a condition is met. This is useful for automating repetitive tasks.

The following are the four types of loops:

  • while loop: evaluates a condition before executing a codeblock.
  • do...while loop: executes a codeblock first then evaluates the condition.
  • for loop: made up of three parts; initialization (executed at the beginning of a loop), condition (evaluated before each execution), increment (executed after the loop, continues if the condition remains true).
  • for-each loop: iterates collections without the need of using indeces.

  • while loop

    This loop allows a code block to be executed repeatedly only if the specified condition remains true.

    If the condition is false, the code block is not executed, and the loop will stop or not run.

    • int counter = 0;

    while (counter <= 5) {
    System.out.println(counter);
    counter++;
    }

  • do...while loop

    This loop allows a code block to be executed first. Then a condition will be evaluated. Once the condition is true, the loop iterates again.

    Even though a condition is false initially, the code block will still be executed once before the condition is evaluated. If the condition remains false, then the loop won't iterate.

    • int counter = 10;

    do {
    System.out.println("counter");
    counter--;
    } while (counter > 5)

  • for loop

    This is a concise way of setting up a iteration structure.

    for (initialization; condition; increment/decrement) { }

    //This one can be useful when iterating through collections like arrays.
    for (datatype element : collection_structure) { }

    This is generally the most useful and reliable loop out of all the loop types.

    • for(int i = 0; i < 10; i++) {
    System.out.println(i);
    }

Object-Oriented Programming Concepts

Classes are an essential aspect of object-oriented programming, acting as the blueprints for objects. Classes allow better code organization and management.

  • Fields: defines the state of the object
  • Constructor: initializing the object's fields
  • Methods: behavior of the object
  • Access Modifiers: specifies the visibility of fields, methods, and classes
public class ClassName {
accessMod dataType field1; //Access modifiers are optional, default to public
dataType field2;

public ClassName(dataType parameter1, dataType parameter2) {
}

returnType MethodName(dataType parameter1, dataType parameter2) {
}
}

  • Methods

    A method is a code block that can perform a task when called upon. It can have receive parameters, which can be set as local variables in the method. Parameters and arguments passed along the method and the main program and both are optional.

    • returnType MethodName(dataType parameter1, dataType parameter2) {
    //code block
    return value; //if returnType is NOT void
    }

    Calling a Method

    objectName.methodName(argument1, argument2);

  • Constructors

    A constructor in Java is a method that is used to initialize fields in an object. Its name must be exactly the same as the class name.

    A default constructor initialize fields to their default value such as 0 for numeric data types, false for booleans, and null if the programmer did not define any constructor. A default constructor can be used to initialize values when no unique data is provided from the main program.

    A parameterized constructor initialize fields with unique values provided from the main program.

    • class ClassName(dataType parameter1, dataType parameter2) {
    accessMod dataType field1;
    accessMod dataType field2;

    public ClassName() {
    //Default Constructor
    this.field1 = null;
    this.field2 = null;
    }

    public ClassName(dataType parameter1, dataType parameter2) {
    //Parameterized Constructor
    this.field1 = parameter1;
    this.field2 = parameter2;
    }

    }
